# ai-personal-tutor

> 制作人：黎木生AI

把你的 AI，变成一个**有约定、会检查、不偷懒的私人家教**。

---

## 它解决什么问题

用 AI 学东西，通常死在两种状态：

| 失败形态 | 表现 |
|---------|------|
| 懒人包 | 你一问，它直接甩答案。你以为会了，其实没学 |
| 降智客服 | 它连问一串，只会说「你再想想」，你永远卡在原地 |

**两种都不会让你真的学会。** 这个 skill 干的事就一件：把 AI 约束成一位真老师——先摸底、再排课、讲完必查、查完分级、进度可存档。

装上之后，AI **自动**按这套教法工作，你不用先给它任何提示词。

## 六步流程

| 步 | AI 做什么 | 产出 |
|----|-----------|------|
| 1 目标确认 | 摸清学什么、为什么学、基础如何 | 《学习目标卡》 |
| 2 备课诊断 | 核对资料 + 诊断起点 + 排课 | 《学习计划》 |
| 3 试听考察 | 围绕一个关键点首轮教学 | 首轮记录 |
| 4 独立检查 | 没讲过的新题考试 + 分级判定 | 通过层级 |
| 5 保存进度 | 导出规则与进度两份文档 | 《助教规则》《学习进度》 |
| 6 续课学习 | 换对话也还是同一个助教 | 持续累积 |

## 六条硬约束

1. **一次一问** — 一次只问一个，等答完再继续
2. **提示优先于答案** — 有思路给提示，缺知识才补讲；不连续反问
3. **进下一知识点前必查理解** — 不用「懂了吗」糊弄
4. **只依据确认过的资料** — 读不到就直说，不编造
5. **练习不给答案** — 看过答案的题不算独立通过
6. **遵守实际规则** — 考试/作业不代做

## 最关键的一条设计

**没有作答证据，就没有通过结论。**

进度分六级：未开始 / 学习中 / 独立通过 / 提示后通过 / 需要补练 / 未测。

AI 不许说「你掌握得很好」就结业。答错了就是答错了，补完再换新题复查——改对旧题也不得改记为通过。

## 安装与使用

放到 WorkBuddy 的 skills 目录下即可：

```
~/.workbuddy/skills/ai-personal-tutor/
```

然后直接说「我要系统学 XX」就行，skill 会自动触发。

## 文件结构

```
ai-personal-tutor/
├── SKILL.md                        # 主文件：AI 的行为指令与六步流程
├── README.md                       # 本文件
└── references/
    ├── prompt-templates.md         # 附录：把这套教法搬到别的 AI 时用的提示词模板

```

## 案例

| 场景 | 最关键的一步 |
|------|------------|
| 学任何科目（以英语为例） | 第4步独立检查暴露「压力下退化成简单句」，退回补练 |
| 自媒体人自己搭智能体 | 第3步校正 AI 直接甩代码，改成先引导定义需求 |
| 运营学 Python 数据处理 | 第4步独立通过，证明只学会了够用的部分 |

案例1 的英语只是例子，换成数学、吉他、考证、任何科目，流程完全一样。

详见 `references/cases.md`。

## 适用边界

好老师的情感互动、状态判断、人格影响，提示词替代不了。这是工具，不是老师。

它适合的是：一门知识你一直想系统学却迟迟没开始，或者不想被卖课博主割韭菜。
